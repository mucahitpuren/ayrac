  <behavior>
    - change('a') → state 'dirty'; after 799ms no save; at 800ms save('a') is called and state is 'saving'; when it resolves → 'saved'
    - change('a'), wait 800ms (save #1 in flight), change('ab'), wait 800ms → no second save starts until #1 resolves; then save('ab') runs; final state 'saved' only after #2 resolves
    - change('x') then flush() → save('x') immediately without waiting for the delay
    - change('   ') → save(null) (whitespace-only note is stored as NULL)
    - save rejects → state 'error' and onState reports it; a later change + 800ms retries with the latest text
    - dispose() cancels a pending timer without saving; flush() after dispose is a no-op
  </behavior>
  <action>
    Write the tests with Vitest fake timers first, then implement `createNoteAutosave({ save, delayMs = 800, onState })`
    as a framework-free controller: one debounce timer, one in-flight promise, and a "pending text" slot; when a save
    settles and a newer text is pending, save it next (single-flight + trailing save). Normalize with `trim()` → empty
    becomes null (the raw text is what the textarea keeps). Report every state transition through `onState`.
