  <name>Task 1: Secrets scanner for build output and git history, netlify.toml, and a clean-history proof</name>
  <read_first>
    - .gitignore, .env.example (01-01), src/lib/client-key.ts (01-02: same JWT-role decoding rule)

  <files>scripts/check-secrets.mjs, tests/unit/check-secrets.test.ts, netlify.toml</files>
  <behavior>
    - A temp dir containing a JS file with an sb_secret_-prefixed 20+ char token → scanner exits 1 and names the file
    - A temp dir containing a JWT whose payload role is service_role → exit 1
    - A temp dir containing an sb_publishable_ key and an anon-role JWT only → exit 0
    - The scanner never prints the matched value (stdout/stderr do not contain the planted token)
  </behavior>
  <action>
    1. `scripts/check-secrets.mjs` (Node ESM, no dependencies): directory mode walks `*.js`, `*.html`, `*.css`, `*.map`, `*.json`
       under the given dir; `--git-history` mode scans the output of `git log -p --all` plus every file from
       `git ls-files`, and also fails if `git log --all --name-only -- data/` lists anything (personal data, P1).
       Findings: tokens starting with `sb_secret_` followed by 10+ `[A-Za-z0-9_-]` chars; JWT-shaped strings whose
       base64url-decoded payload has `role` === the service role (same decode rule as `src/lib/client-key.ts`);
       and — only if the local gitignored env files exist — literal occurrences of the values of
       TEST_SUPABASE_SERVICE_ROLE_KEY, SUPABASE_DEV_DB_PASSWORD, SUPABASE_PROD_DB_PASSWORD (values of length >= 12).
       Report `file: kind` lines only, never the value; exit 1 on any finding, else print `no secrets found in N files`.
    2. `tests/unit/check-secrets.test.ts`: build the fake tokens at runtime by string concatenation (so this test
       file itself never contains a secret-shaped literal that would trip the history scan), write them into
       `fs.mkdtempSync(os.tmpdir())` dirs, run the script with `spawnSync(process.execPath, ['scripts/check-secrets.mjs', dir])`,
       assert the behavior block.
    3. `netlify.toml`: `[build] command = "npm run build && node scripts/check-secrets.mjs dist"`, `publish = "dist"`;
       `[build.environment] NODE_VERSION = "22"` and `SECRETS_SCAN_OMIT_KEYS = "VITE_SUPABASE_URL,VITE_SUPABASE_ANON_KEY"`
       with a comment that these two are public by design (the anon/publishable key only works through RLS) while
       our own scanner still blocks secret keys; `[[redirects]] from = "/*" to = "/index.html" status = 200`;
       `[[headers]] for = "/*"` with `X-Content-Type-Options = "nosniff"`, `X-Frame-Options = "DENY"`,
       `Referrer-Policy = "strict-origin-when-cross-origin"`, `Permissions-Policy = "camera=(), microphone=(), geolocation=()"`;
       `[[headers]] for = "/assets/*"` with `Cache-Control = "public, max-age=31536000, immutable"`.
    4. Run `npm run build && node scripts/check-secrets.mjs dist` and `node scripts/check-secrets.mjs --git-history`;
       both must pass before Task 2 lets anything be pushed.
  </action>
  <verify>
    <automated>npm run test:unit -- tests/unit/check-secrets.test.ts && npm run build && node scripts/check-secrets.mjs dist && node scripts/check-secrets.mjs --git-history</automated>
    <fails_when>non-zero exit from any step, or vitest prints "No test files found"</fails_when>
  </verify>

    - `netlify.toml` contains `publish = "dist"`, `to = "/index.html"`, `status = 200`, `NODE_VERSION = "22"`, `nosniff`
  </acceptance_criteria>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| local repo → public GitHub | Entire history becomes public |
| Netlify build → public CDN | Everything in dist/ is public |
| Netlify env vars → bundle | VITE_ values are inlined into JS |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-07-01 | Information Disclosure | secret key or DB password in git history | high | mitigate | `--git-history` scan must pass before the first push (Task 1 → Task 2 ordering); GitHub push protection on |
| T-01-07-02 | Elevation of Privilege | secret key placed in a VITE_ Netlify variable | high | mitigate | Build command runs the dist scanner; `assertClientSafeKey` throws at runtime; env vars not flagged secret only for the two public values |
| T-01-07-03 | Information Disclosure | personal data/ folder pushed | high | mitigate | Scanner fails if `data/` appears anywhere in history (P1); `.gitignore` |
| T-01-07-04 | Tampering | deploy previews writing to the real library | medium | mitigate | Per-context env vars: previews/branches → dev project |
| T-01-07-05 | Tampering | later `db push` accidentally hitting prod | medium | mitigate | CLI relinked to dev immediately after the prod push; verify asserts the linked ref |
| T-01-07-06 | Spoofing | clickjacking / MIME sniffing | low | mitigate | X-Frame-Options DENY, nosniff, Referrer-Policy headers |
| T-01-07-07 | Tampering | no Content-Security-Policy yet | low | accept | Phase 1 has no third-party scripts or images; CSP to be designed in Phase 4 when external cover hosts arrive |
</threat_model>
